# It's Candy's Classic Touch

The website for **It's Candy's Classic Touch** — a hair salon in Muckleneuk / Sunnyside, Pretoria.

**Live site:** https://<your-username>.github.io/candys-classic-touch/

## What's here

`index.html` — the entire site. One self-contained file. Every photograph and
illustration is embedded, so it works offline and there is nothing else to upload.

## How it's published

1. Create a **public** repository named `candys-classic-touch`
2. Upload `index.html`, `.nojekyll` and this README
3. **Settings → Pages → Source: Deploy from a branch → `main` / `(root)` → Save**
4. Give it a minute, then open the link above

`.nojekyll` stops GitHub's Jekyll build from touching the file.

## Updating

Replace `index.html` and commit. GitHub Pages redeploys on its own.
